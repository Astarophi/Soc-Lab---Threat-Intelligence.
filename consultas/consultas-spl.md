# Consultas do SOC Lab

Esta pasta reúne as consultas desenvolvidas em Search Processing Language (SPL) utilizadas para análise dos eventos coletados pelo laboratório.

## Consultas planejadas

- Monitoramento de requisições HTTP.
- Identificação dos endereços IP de origem.
- Análise de códigos de resposta HTTP.
- Identificação de atividades suspeitas.
- Análise de informações de geolocalização.
- Investigação de reputação de endereços IP.
- Análise de eventos de Threat Intelligence.

As consultas serão documentadas com suas respectivas finalidades e explicações.
